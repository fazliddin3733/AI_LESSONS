Bu darsda supervised learningga yanada chuqurroq kirib uning turlarini o'rgandik.Supervised learning classification va linear ga bo'linadi.Agar output cheklangan qiymatda bo'lsa masalan 2 ta yo 3 ta bir birini takrorlaydigan bo'lsa bu classification bo'ladi.Agar output bir birini takrorlamaydigan ko'p miqdorda bo'ladigan bo'lsa masalan uy narxini predict qilganda narxlar bir biridan farq qiladigan darajada bu linear deyiladi.Classification o'z navbatida ikki turga bo'linadi faqat 2 ta outputdan iborat bo'lsa bu binary deyiladi undan ko'p bo'sa masalan 3 ta bu multiclass deyiladi.Bundan tashqari model yaratishda asosiy boshqichlarni ko'rib chiqdik data collectiondan tortib monitoringgacha.Va Kaggle bilan tanishib undan data yuklab oldik.Data ustida amallar bajarib ko'rdik.Pythondan conditionlar bilan tanishdim if yani shart operatori desak ham bo'ladi.
