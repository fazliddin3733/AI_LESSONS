Bu dars mobaynida Project ketma ketligini hamda Data preprocessing ni o'rgandim.Data preprocessing bu datani tayyorlab olish yani bizda mavjud bo'lgan datani train qilishdan oldin unda qolib kegan qiymatlar yo'qmi tekshirib bor bo'lsa ularni turli xil usullarda to'ldirish.
Mean()-o'rta arifmetik qiymatni olib ketadi faqat raqamli datalarda ishlaydi sababi string da o'rta arifmetik yo'q.
Mode()-eng ko'p takrorlangan element bilan to'ldirib ketadi bunda farqi yo'q stringda ham sonlarda ham ketaveradi.
Median()-o'rtasidagi element bilan to'ldirib ketadi ko'proq raqamli uchun.
Fixed qiymatlar bilan o'zimiz qo'lda to'ldirsak ham bo'ladi.
Data setdagi holatdan kelib chiqib qaror qabul qilinadi masalan natijaga uncha bog'liq bo'lmagan ustun bo'lsa va juda ko'p qiymatlari kam bo'lsa uni to'ldirgandan ko'ra tashlab yuborgan yahshi.Chunki bu taxminiy to'ldirilgan qiymatlar ular fakt emas shuning uchun kelajakda modelni ishlashiga ham tasir qilishi mumkin.
Kutubxonalar bizni nima yo'nalishda ishlashimizga qarab tuzilgan bo'lib bizga shu yo'nalishda qulaylik beradi.Numpy,Pandas,Seaborn,Matplotlib,Scikit learn kabilar mavjud.
Numpy-matimatik hisob kitoblar matritsalar bilan ishlaganda kerak.
Pandas-Data freme bilan ishlaganimizda kerak.
Matplotlib-vizualizatsiya bo'yicha.
Seaborn-statistic hisob kitoblarni vizual ko'rinishda tasvirlab beradi.
Scikit learn-Modelni train qilishda.
